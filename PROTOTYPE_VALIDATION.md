# Prototype Validation

This repository has undergone technical prototype validation, not a formal user pilot.

Automated tests check that a data-oriented profile ranks a data-skills opportunity above an unrelated creative opportunity, an empty profile does not generate misleading recommendations, and malformed opportunity data is rejected.

The project does not currently claim statistically representative user testing, placement outcomes, recommendation-accuracy percentages or validated impact. Those should only be reported after documented user research or a structured pilot.
