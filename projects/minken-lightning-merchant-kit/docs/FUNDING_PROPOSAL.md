# LAB Open Source Builder Fund — project concept

## Project Name
Minken Lightning Merchant Kit (MLMK)

## Builder / Team
Minken Investment Ltd (Minken Africa) is the proposed Kenyan sponsor. Hukun Ali Dabar is the organisational contact. The qualified African Bitcoin/Lightning engineering lead and named technical contributors have not been confirmed.

## Location
Nairobi, Kenya.

## GitHub Repository
This folder is hosted within the existing public Minken youth opportunity repository. It is a separate code project but **not yet a standalone GitHub repository**. No live Lightning integration is claimed.

## Problem Statement
African merchant application developers need reusable reference designs for Lightning invoices, asynchronous confirmation, webhook reliability and low-bandwidth checkout flows.

## Technical Approach
The proposed MIT-licensed toolkit will evolve from the current mock-only TypeScript scaffold to an isolated Lightning regtest adapter, status handling and a small reference merchant checkout. Documentation, security testing, and reproducible CI will be public. Custody, exchange, M-PESA production integration and fiat settlement are out of scope.

## Ecosystem Focus
Lightning infrastructure / developer tooling.

## Current Project Stage
Starter mock TypeScript code and four offline tests; no working Lightning node, wallet or payable invoices.

## Milestones
1. Foundation and contributor governance (February 2027).
2. Isolated regtest invoice adapter and tests (March 2027).
3. Checkout, webhook and idempotency examples with security review (April 2027).
4. v1 release and English/Swahili documentation (May 2027).
