# Contributing

MLMK is currently a mock-only starter project. Contributions to architecture, tests, threat models and open-source implementation are welcome.

1. Open an issue describing the change before major development.
2. Include tests and documentation with new code.
3. Never commit credentials, wallet seeds, real merchant data or private keys.
4. Use regtest and offline fixtures; production work requires independent security review.
5. Contributions are provided under the MIT licence.

Minken Investment Ltd is the project sponsor; permanent technical maintainership remains to be appointed.
